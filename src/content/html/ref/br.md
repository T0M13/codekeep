# &lt;br&gt;

Inserts a single line break.

## Syntax

```html
Line one<br>
Line two
```

## Attributes

| Attribute | Description | Example |
|-----------|-------------|---------|
| None specific | Self-closing, no unique attributes | — |

## Key Points

- Self-closing tag — no end tag needed
- Use for content where line breaks are meaningful (addresses, poems)
- Do **not** use `<br>` to create spacing between elements — use CSS margins instead
- Multiple `<br>` tags in a row is considered bad practice
- Inline element

## Example

```html
<!-- Address with meaningful line breaks -->
<p>
  123 Main Street<br>
  Apartment 4B<br>
  New York, NY 10001
</p>

<!-- Poem -->
<p>
  Roses are red,<br>
  Violets are blue,<br>
  HTML is fun,<br>
  And so are you.
</p>
```
