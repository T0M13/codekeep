# &lt;h1&gt; - &lt;h6&gt;

Define headings, from most important (`<h1>`) to least important (`<h6>`).

## Syntax

```html
<h1>Main Heading</h1>
<h2>Subheading</h2>
<h3>Sub-subheading</h3>
```

## Attributes

| Attribute | Description | Example |
|-----------|-------------|---------|
| Global only | Headings have no unique attributes | `id="intro"` |

## Key Points

- `<h1>` is the highest level, `<h6>` is the lowest
- Use only one `<h1>` per page (for SEO and accessibility)
- Do not skip heading levels — go `h1` then `h2` then `h3`, etc.
- Headings are block-level elements (take full width, start on a new line)
- Search engines use headings to understand page structure
- Do not use headings just to make text big — use CSS for styling

## Example

```html
<h1>HTML Reference Guide</h1>

<h2>Getting Started</h2>
<p>Learn the basics of HTML.</p>

<h3>What is HTML?</h3>
<p>HTML stands for HyperText Markup Language.</p>

<h3>Your First Page</h3>
<p>Create a simple HTML document.</p>

<h2>Advanced Topics</h2>

<h3>Semantic HTML</h3>
<h4>Why Semantics Matter</h4>
<p>Semantic tags improve accessibility and SEO.</p>
```
