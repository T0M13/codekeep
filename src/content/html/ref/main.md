# &lt;main&gt;

The `<main>` element contains the content that is unique and central to the current page.

## Syntax

```html
<body>
  <header>Site navigation</header>
  <main>
    <h1>Account settings</h1>
    <p>Update your profile and preferences.</p>
  </main>
  <footer>Site information</footer>
</body>
```

## Key points

- Use one visible `<main>` per document.
- Do not place `<main>` inside `<article>`, `<aside>`, `<footer>`, `<header>`, or `<nav>`.
- Repeated site-wide navigation and footer content belong outside it.

## Difference from `<body>` and `<section>`

`<body>` contains the whole visible document. `<main>` identifies its dominant content. A `<section>` groups one themed part of that content and normally has a heading.
