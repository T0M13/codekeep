# &lt;title&gt;

Defines the title of the document, shown in the browser tab and search results.

## Syntax

```html
<title>Page Title</title>
```

## Attributes

| Attribute | Description | Example |
|-----------|-------------|---------|
| None specific | The `<title>` element has no unique attributes | — |

## Key Points

- Required in every HTML document
- Must be placed inside `<head>`
- Only one `<title>` per document
- Used by browsers (tab title), search engines (result title), and bookmarks
- Should be descriptive and concise (50-60 characters recommended for SEO)
- Text only — no other HTML tags allowed inside

## Example

```html
<head>
  <title>CodeKeep - Learn HTML the Fun Way</title>
</head>
```
